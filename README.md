# StarCommand

Your own AI command centre: a boss AI and a team of worker AIs that research, design, list products, make videos and more, all running on your computer.

This repository holds the program updates only. Your agents, chats, keys and files never leave your computer.

## Install

1. Download the newest zip from the `releases` folder and extract it.
2. Double-click `install.bat` (Windows). StarCommand adds a desktop and Start-menu icon.
3. From then on, StarCommand updates itself from `version.json` in this repository.
